## 3. 현재 기능 브랜치 작업

다음 작업은 `feature/map-grid-collision` 브랜치에서 관리한다. `main`에는 직접 반영하지 않는다.

### 새 맵 적용

- 게임에 표시되는 맵을 `map-base.png`에서 `MapGrid.png`로 변경했다.
- `MapGrid.png`의 실제 맵 구역인 `(301, 529, 3520, 1216)`을 게임 월드에 맞춰 그린다.
- 기존 캐릭터, 아이템, 괴물, 목표 좌표를 그대로 사용할 수 있도록 월드 크기는 `3520×1216`으로 유지했다.

### 벽 충돌 강화

- 기존 `map-base.png`는 화면에 표시하지 않고 충돌 마스크로만 사용한다.
- 충돌 마스크를 64px 단위로 분석한다.
- 각 타일에서 바닥색 픽셀이 70% 이상인 경우에만 이동 가능한 바닥으로 판정한다.
- 벽의 밝은 테두리를 바닥으로 잘못 인식해 캐릭터가 벽에 올라가는 문제를 방지했다.
- 분석 결과 이동 가능한 타일 486개가 하나의 연결된 구역으로 이어져 있다.
- 시작점, 괴물, 목표, 아이템 위치가 모두 이동 가능한 타일 위에 있는 것을 확인했다.
